# ShareRoom

> Compartilhamento privado de tela e áudio em tempo real.

O **ShareRoom** é um aplicativo desktop para Windows criado para compartilhar uma tela ou janela com outras pessoas de forma simples, rápida e privada.

A transmissão é iniciada pelo aplicativo desktop e os espectadores acessam diretamente pelo navegador através de um **link temporário exclusivo para cada transmissão**.

---

## ✨ Recursos

- Compartilhamento de tela inteira
- Compartilhamento de janelas individuais
- Áudio do sistema
- Áudio exclusivo da janela compartilhada
- Viewer diretamente pelo navegador
- Links privados e temporários por transmissão
- Limite configurável de espectadores
- Troca de tela sem encerrar a transmissão
- Resoluções 720p e 1080p
- 30 FPS e 60 FPS
- Interface desenvolvida especialmente para o ShareRoom
- Transmissão em tempo real utilizando WebRTC

---

## 🖥️ Como funciona

O fluxo do ShareRoom é simples:

**1.** Abra o ShareRoom no Windows  
**2.** Escolha uma tela ou janela  
**3.** Configure a qualidade da transmissão  
**4.** Inicie a transmissão  
**5.** Copie o link gerado  
**6.** Envie o link para quem deseja assistir  
**7.** O espectador abre o link diretamente no navegador

Não é necessário instalar nenhum aplicativo para assistir.

---

## 🔒 Privacidade

Cada transmissão cria uma sessão independente com um novo acesso privado.

Um link de uma transmissão anterior não permite acessar automaticamente uma transmissão futura.

O ShareRoom também permite definir previamente quantas pessoas poderão entrar na transmissão.

---

## 🛠️ Tecnologias

O ShareRoom foi desenvolvido utilizando:

- **Electron**
- **React**
- **TypeScript**
- **Vite**
- **Node.js**
- **LiveKit**
- **WebRTC**
- **Express**
- **PostgreSQL / Neon**
- **Vercel**
- **Windows WASAPI**

O áudio de tela e de aplicações utiliza captura nativa no Windows.

## 📌 Sobre o projeto

O ShareRoom nasceu como um projeto independente com o objetivo de explorar tecnologias de transmissão em tempo real, aplicações desktop com Electron, WebRTC e captura nativa de áudio no Windows.

O código-fonte principal do projeto é mantido em um repositório privado.

Este repositório é destinado à apresentação do projeto, documentação e distribuição das versões públicas.
